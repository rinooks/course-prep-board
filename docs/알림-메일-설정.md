# 알림 메일 설정 가이드

강의 준비 보드는 매일 아침 9시쯤 두 가지 알림을 메일로 보냅니다.

| 알림 | 언제 | 누구에게 |
|---|---|---|
| 내일 강의 | 강의 전날 | 그 과정의 담당 강사 |
| 미입금 강사료 | 입금 예정일 다음 날, 그 뒤 입금일을 적을 때까지 7일마다 | 그 강사 본인 + 모든 관리자 |

같은 내용은 앱 머리글의 종 버튼과 홈 화면 위쪽에도 보입니다. 앱 안 알림은 아래 설정이 없어도 동작합니다.
**메일만** 아래 설정이 필요합니다. 처음 한 번만 하면 됩니다 (30분쯤 걸립니다).

---

## 0. 준비할 값 4개

메일을 보내려면 아래 4가지 값을 Vercel에 넣어야 합니다.

| 이름 | 무엇인지 | 어디서 만드는지 |
|---|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 서버가 Firestore를 읽을 때 쓰는 열쇠 | Firebase 콘솔 (1단계) |
| `GMAIL_USER` | 메일을 보내는 Gmail 주소 | 이미 있는 주소 (예: owner@example.com) |
| `GMAIL_APP_PASSWORD` | 그 Gmail 계정의 앱 비밀번호 16자리 | 구글 계정 설정 (2단계) |
| `CRON_SECRET` | 매일 아침 작업을 Vercel만 부를 수 있게 하는 무작위 암호 | 직접 만듦 (3단계) |

> **환경 변수** — 코드 밖에 따로 보관하는 설정값입니다.
> 비밀번호를 코드에 적으면 GitHub에 올라가 누구나 볼 수 있게 됩니다. 환경 변수로 두면 Vercel 서버 안에만 있고 코드에는 이름만 남습니다.
> 이 앱에서는 위 4개가 모두 환경 변수입니다. 이름 앞에 `NEXT_PUBLIC_`을 **절대 붙이지 않습니다** (붙이면 브라우저로 내려가 누구나 볼 수 있습니다).

---

## 1단계. 서비스 계정 키 만들기 (`FIREBASE_SERVICE_ACCOUNT`)

> **서비스 계정 키** — 사람이 아니라 "서버 프로그램"이 Firebase에 로그인할 때 쓰는 열쇠 파일(JSON)입니다.
> 평소 앱은 로그인한 사람의 권한으로만 데이터를 읽지만, 매일 아침 메일 작업은 아무도 로그인하지 않은 채 돌아가므로 이 열쇠가 필요합니다.
> **주의:** 이 열쇠는 보안 규칙을 거치지 않고 모든 데이터를 읽고 쓸 수 있습니다. 비밀번호보다 더 조심해서 다룹니다.

1. https://console.firebase.google.com 에 `owner@example.com`으로 로그인합니다.
2. 프로젝트 **edu-project-f1d12**를 엽니다.
3. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 위쪽 **서비스 계정** 탭을 누릅니다.
4. **새 비공개 키 생성** → **키 생성**을 누르면 JSON 파일이 내려받아집니다.
5. 그 파일을 메모장으로 열고, **처음 `{` 부터 마지막 `}` 까지 전체**를 복사합니다. 이것이 `FIREBASE_SERVICE_ACCOUNT` 값입니다.

지켜야 할 것
- 이 파일을 프로젝트 폴더(`D:\vibe\05 AIHR-vibecording`) 안에 두지 않습니다. 실수로 GitHub에 올라갈 수 있습니다.
- 메신저·메일로 보내지 않습니다.
- Vercel에 넣고 나면 내려받은 파일은 지워도 됩니다. 다시 필요하면 새 키를 만들면 됩니다.

---

## 2단계. Gmail 앱 비밀번호 만들기 (`GMAIL_USER`, `GMAIL_APP_PASSWORD`)

> **앱 비밀번호** — 구글 계정 비밀번호 대신, 특정 프로그램 하나에만 주는 16자리 비밀번호입니다.
> 진짜 비밀번호를 서버에 넣어 두면 새었을 때 계정 전체를 잃습니다. 앱 비밀번호는 메일 보내기에만 쓰이고, 언제든 이것만 지울 수 있습니다.
> 구글은 **2단계 인증**(비밀번호 + 휴대폰 확인)을 켠 계정에만 앱 비밀번호를 만들어 줍니다.

1. 메일을 보낼 Gmail 계정(예: `owner@example.com`)으로 https://myaccount.google.com 에 로그인합니다.
2. 왼쪽 **보안** → **2단계 인증**이 꺼져 있으면 켭니다 (휴대폰 확인).
3. https://myaccount.google.com/apppasswords 로 갑니다.
4. 앱 이름에 `강의 준비 보드`라고 적고 **만들기**를 누릅니다.
5. 화면에 뜬 16자리(`abcd efgh ijkl mnop` 모양)를 복사합니다. 띄어쓰기가 있어도 괜찮습니다. 이 창을 닫으면 다시 볼 수 없으니 바로 4단계로 넘어가 Vercel에 넣습니다.

- `GMAIL_USER` = 그 Gmail 주소 (예: `owner@example.com`)
- `GMAIL_APP_PASSWORD` = 방금 만든 16자리

한계: 무료 Gmail은 하루에 약 500통까지 보낼 수 있습니다. 팀원 20명이면 하루 많아야 20통이라 충분합니다.

---

## 3단계. `CRON_SECRET` 만들기

> **크론(Cron)** — "매일 몇 시에 이 주소를 불러라" 하고 예약해 두는 기능입니다.
> 이 앱은 `vercel.json`에 "매일 00:00(UTC) = 한국 오전 9시에 `/api/cron/daily`를 불러라"라고 적어 두었습니다.
> 그런데 이 주소는 인터넷에 열려 있어서, 아무나 불러 메일을 보내게 할 수도 있습니다.
> `CRON_SECRET`을 넣어 두면 Vercel이 부를 때 이 암호를 같이 보내고, 앱은 암호가 맞을 때만 작업합니다.

무작위 값을 만듭니다. 컴퓨터의 PowerShell(또는 VS Code 터미널)에 아래 한 줄을 붙여 넣으면 64글자짜리 값이 나옵니다.

```
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

나온 값 전체를 복사해 둡니다. 16자 이상이어야 하고, 사람이 정한 단어(생일, 이름 등)는 쓰지 않습니다.

## 4단계. Vercel에 환경 변수 넣기

1. https://vercel.com 에 로그인 → 이 앱 프로젝트를 엽니다.
2. 위쪽 **Settings** → 왼쪽 **Environment Variables**로 갑니다.
3. 아래 4개를 하나씩 추가합니다. 각각:
   - **Key**: 이름 (예: `GMAIL_USER`)
   - **Value**: 1~3단계에서 복사한 값
   - **Environments**: **Production**만 체크합니다 (미리보기 배포에서는 메일이 나가지 않게)
   - **Sensitive** 스위치가 보이면 켭니다 (넣은 뒤에는 화면에서도 값이 가려집니다)
4. (선택) 앱 주소가 바뀌었다면 `APP_BASE_URL`에 새 주소(예: `https://edu-project-beta.vercel.app`)를 넣습니다. 비워 두면 이 주소를 씁니다.

| Key | Value |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 키 JSON 전체 |
| `GMAIL_USER` | 보내는 Gmail 주소 |
| `GMAIL_APP_PASSWORD` | 앱 비밀번호 16자리 |
| `CRON_SECRET` | 3단계에서 만든 값 |

---

## 5단계. 다시 배포하기

환경 변수는 **새로 배포한 뒤부터** 적용됩니다.

- Vercel 프로젝트 → **Deployments** → 맨 위 배포 오른쪽 `⋯` → **Redeploy**를 누릅니다.
- 또는 코드를 `main`에 올리면 자동으로 다시 배포됩니다.

배포가 끝나면 **Settings → Cron Jobs**에 `/api/cron/daily` (`0 0 * * *`)가 보이는지 확인합니다.

---

## 6단계. 테스트 메일 보내기

1. 앱에 관리자로 로그인 → 머리글 **관리자** → 아래쪽 **알림 메일** 구역으로 갑니다.
2. **나에게 테스트 메일 보내기**를 누릅니다.
3. 1~2분 안에 내 메일함(없으면 스팸함)에 "[강의 준비 보드] 테스트 메일"이 오면 설정 끝입니다.

실패했을 때 화면에 뜨는 안내를 보고 아래처럼 고칩니다. 고친 뒤에는 **5단계(다시 배포)**를 꼭 다시 합니다.

| 안내 문구에 들어 있는 말 | 고칠 곳 |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 1단계 키 JSON을 처음 `{`부터 끝 `}`까지 빠짐없이 넣었는지 |
| `GMAIL_USER`, `GMAIL_APP_PASSWORD`, "Gmail 로그인에 실패" | 2단계 주소와 앱 비밀번호. 앱 비밀번호를 새로 만들어 바꿔 넣기 |
| "1분에 한 번만" | 1분 기다렸다가 다시 누르기 |
| "관리자만" | 관리자 계정으로 로그인했는지 |

## 매일 아침에는 이렇게 동작합니다

- Vercel 무료(Hobby) 플랜은 정확한 시각을 보장하지 않아, **오전 9:00~9:59 사이** 아무 때나 실행됩니다.
- 알릴 내용이 없는 사람에게는 메일을 보내지 않습니다. 한 사람에게 하루 한 통만 갑니다 (내일 강의 + 미입금 강사료를 한 통에 모음).
- 같은 날 작업이 두 번 실행되어도 같은 사람에게 두 번 가지 않습니다. Firestore의 `mailLog` 모음에 "오늘 보냄" 표시를 남기기 때문입니다.
  이 표시에는 이메일 주소 대신 알아볼 수 없게 바꾼 값(해시)만 들어가고, 30일이 지나면 저절로 지워집니다.
- 메일 보내기에 실패한 사람은 표시를 남기지 않으므로, 같은 날 다시 실행하면 그 사람에게만 다시 보냅니다.
- 실행 결과는 Vercel 프로젝트 → **Logs**에서 `/api/cron/daily`로 찾아볼 수 있습니다 (보낸 수·실패 수만 남고 주소는 남지 않습니다).
- 지금 바로 한 번 실행해 보고 싶으면 **Settings → Cron Jobs**의 `/api/cron/daily` 옆 **Run**을 누릅니다.

## 키나 비밀번호가 새었을 때

새었다고 의심되면 지우고 새로 만드는 것이 가장 빠르고 확실합니다. 파일만 지우는 것으로는 부족합니다.

**서비스 계정 키**
1. Firebase 콘솔 → 프로젝트 설정 → 서비스 계정 탭 → **서비스 계정 권한 관리**(Google Cloud 콘솔로 이동)를 누릅니다.
2. `firebase-adminsdk-…` 계정 → **키** 탭에서 새었을 수 있는 키를 **삭제**합니다. 삭제하는 즉시 그 키로는 아무것도 할 수 없습니다.
3. 1단계대로 새 키를 만들어 Vercel의 `FIREBASE_SERVICE_ACCOUNT`를 바꾸고 다시 배포합니다.

**Gmail 앱 비밀번호**
1. https://myaccount.google.com/apppasswords 에서 `강의 준비 보드`를 삭제합니다.
2. 새로 만들어 Vercel의 `GMAIL_APP_PASSWORD`를 바꾸고 다시 배포합니다.

**CRON_SECRET**
- 3단계대로 새 값을 만들어 Vercel에서 바꾸고 다시 배포합니다.

GitHub에 올라간 적이 있다면 커밋 기록에 남아 있으므로, 파일을 지운 것과 상관없이 **반드시** 위처럼 폐기하고 새로 만듭니다.
